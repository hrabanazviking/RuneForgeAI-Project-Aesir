      --sha256 <digest> --size <bytes> [--output <path>] [--connections 1..8]
      [--name <name[:tag]> [--config <path>]]
      Download and verify a pinned GGUF; optionally register stored bytes.
      Default single-connection pulls resume verified partial downloads.
  inspect <model> [--format text|json] [--context N] [--model-store path]
      Report architecture, adapter readiness, capabilities, and memory estimate.
  doctor [model] [--model-store path] [--format text|json]

      Preview by default; --apply removes only shortcuts to missing catalog models.
      Durable local shortcuts and favorite-first interactive selection.
  run <model> [--max-tokens N] [--config path] [--accel auto|cpu|cuda] <prompt...>
      CPU GGUF or auto-detected native CUDA Gemma4/Llama3/Qwen3 single-shot inference.

      Omit model to choose an installed catalog model interactively.
      --show-settings with an explicit model previews native config/recipe/CLI settings as JSON; no GPU load.
      [--temperature 0] [--top-k 40] [--top-p 0.95] [--min-p 0]
      [--timeout-ms 0] (per-turn deadline; 0 disables); Ctrl+C cancels generation
      [--repeat-penalty 1] [--repeat-last-n 64] [--seed 42]
      [--autosave-dir existing-private-directory] [--autosave-retain 1..64]
      Optional crash recovery; restores the latest compatible committed generation.
      Interactive: /help /show /clear /new /model <name-or-alias> /save <new-file> /load <file>
      /export <new-markdown> /set <setting> <value> /bye
      Defaults: context auto-fits observed CUDA memory; replies use at most half of it, capped by family.
      Persistent CUDA text chat; one user turn per nonempty prompt-file line.
  config [--config <path>] [--format json|text]
      Validate and show the selected configuration file.
  list|ls [--config path] [--format text|json]
  show <name[:tag]> [--config path] [--format text|json]
  create <name[:tag]> --modelfile <path> [--model <weights>] [--config path]
  verify <name[:tag]> [--config path]
  catalog migrate|backup|restore <path> [--model-store path | --config file]
      One-way legacy import and immutable validate-before-replace snapshots.
  gc [--config path]
  cp <source[:tag]> <target[:tag]> [--config path]
  rm|delete <name[:tag]> [--config path]
      Restart-safe catalog operations; default store is .aesir/models.
      Select a store with --model-store path OR --config file (not both).
      --model imports immutable SHA-256-addressed bytes; verify rehashes them.
  help, -h, --help
      Show this capability-aware help.
  -v, --version
      Show the development version.

  serve <model> --accel cuda --api-key-file <private-file>
