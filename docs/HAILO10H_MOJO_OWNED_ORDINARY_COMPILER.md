## Implementation

New `smidr/owned_ordinary_compiler.mojo` retains an indexed/unindexed owned
ordinary binding, independent ExpandedGraph and owned explicit invocation request.
Factories compose the published loaders. Compilation revalidates actual sealed
owners and bounded aggregate/per-file hash permits, rehydrates existing parsers
and compares complete retained source intent. No new parser, alias, dtype, hash,
recipe or aggregate-sort algorithm, raw OS interface or external model compiler
is introduced. All675 old Mojo and74 old Python sources remain exact.

The existing qualified source interpreters provide geometry, output/tie choice,
rotary flags, bias flags, activation, session, windows and default/linear scaling.
Exact binary64 source scalars propagate without implicit narrowing. Raw fields,
source/default origins, aliases, namespaces/axes/extents and unresolved decisions
stay in the retained binding. Rotary width/pairing and invocation session choices
are explicit bounded mathematical decisions with provenance. Other variants and
complete architecture adaptation remain required work. Inspector arguments are
diagnostic test inputs, not a user conversion workflow.

The one semantic builder consumes an independently rederived temporary inventory;
the retained guard binding stays populated and independently owned. Before a
static read, actual source intent is compared with graph source inventory and
owned/supplied policy/request. Existing builders rederive the selected semantic
operation and geometry/policies. Every consumed selector, scalar/policy, source
binding and referenced tensor field is checked before using the existing owned
binding component helper. Guard scope is semantic component selection: unconsumed
expanded operations, recipes and values are not a generic immutable artifact.

Windows own their data after close. Existing collection cleanup attempts every
owner and preserves the first reported raising error; Safetensors close retains
its nonraising limitation. No consuming compile/read path reopens source paths,
duplicates descriptors, remaps or substitutes a borrowed owner.
