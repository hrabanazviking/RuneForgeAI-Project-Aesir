- **The rules (pre-registered; the module header is their normative text; answered-locally, §6).** A file's fate as an MTP drafter source is decided by `core/mtp_head_support.mojo`'s `evaluate_mtp_admission(file_name, directory_read, tensor_names)`, in this order: (1) an empty file name is refused (`REFUSE_EMPTY_FILE_NAME`); (2) a file whose directory was **not** read is refused as **NOT PROVEN** (`REFUSE_NOT_PROVEN`) — names carried beside it are never trusted, counted, or classified; (3) a read directory is classified **only** through J-076's `MtpCensus` (the classifier is bound, not restated — the support module contains no substring rule of its own): **WITH_MTP → ADMITTED** as a drafter source, every head tensor named in directory order with its J-076 kind; **NO_MTP → REFUSED BY NAME** (`REFUSE_NO_MTP`); **VOCAB_ONLY → REFUSED BY NAME** (`REFUSE_VOCAB_ONLY`). A refusal is a named record (file + verdict + reason, rendered by `mtp_refusal_line`), never a fallback: a refused admission yields **no** proposer shape — `admitted_proposer_shape` raises on it — so no code path can turn an MTP refusal into a plain run by accident. Files without heads are refused by name, never silently plain — that is the roadmap's sentence, made mechanical.
