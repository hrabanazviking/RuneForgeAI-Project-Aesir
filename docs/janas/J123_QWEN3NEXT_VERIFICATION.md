### 0.4 The layout (public record + filed header facts, with its one arithmetic witness)

From the public model card / Qwen team description: 48 layers in the repeating pattern 3 × (Gated DeltaNet → MoE) then 1 × (Gated Attention → MoE) — i.e. every `full_attention_interval`-th layer (interval 4, 1-based) is an attention layer, the rest are Gated-DeltaNet SSM layers (36 SSM / 12 attention). Gated Attention: 16 Q heads, 2 KV heads, head dim 256 (Q width 4096, KV width 512 at the real geometry), partial RoPE (64 of 256 dims). Gated DeltaNet: 32 value heads / 16 QK heads, head dim 128, SSM inner 4096. MoE on every block: 512 routed experts, top-10, expert width 512, plus 1 shared expert of width 512 (`expert_shared_feed_forward_length`).

Per-block tensor directory (names are the GGUF naming forms of this arch family, as filed for `qwen35` in this tree's own validator and for the routed/shared experts in the `olmoe` validator):

- **Common (9 per block):** `attn_norm.weight`, `post_attention_norm.weight` (the pre-FFN norm role, as in `qwen35` — no `ffn_norm`), `ffn_gate_inp.weight` (router), `ffn_gate_exps.weight`, `ffn_up_exps.weight`, `ffn_down_exps.weight` (routed experts, stored 3-D and folded by the tensor parser exactly as for `olmoe`), `ffn_gate_shexp.weight`, `ffn_up_shexp.weight`, `ffn_down_shexp.weight` (shared expert).
- **SSM block (+9 = 18):** `attn_qkv.weight`, `attn_gate.weight`, `ssm_alpha.weight`, `ssm_beta.weight`, `ssm_a`, `ssm_conv1d.weight`, `ssm_dt.bias`, `ssm_norm.weight`, `ssm_out.weight` (the `qwen35` SSM set, unchanged).
- **Attention block (+7 = 16), gated, either form:** separate-gate form — `attn_q.weight` (Q width), `attn_k.weight`, `attn_v.weight`, `attn_output.weight`, `attn_q_norm.weight`, `attn_k_norm.weight` (per-head, head-dim wide, as in `qwen35`), `attn_gate.weight` (Q width); **or** fused-gate form — `attn_q.weight` at twice Q width (the `qwen35` fused form) with no `attn_gate.weight`. The validator admits either and refuses a gate whose width matches neither.
- **Globals (3):** `token_embd.weight`, `output_norm.weight`, `output.weight`.

**Census arithmetic (the witness):** 36 × 18 + 12 × 16 + 3 = **843** — exactly the tensor count J-022's header read filed for the real file. This agreement is recorded as MEASURED-INDICATIVE support for the directory above, not as the real file's census: only the §0.1(b) header census on the file itself can prove the directory, and per-tensor shapes for the SSM internals (`attn_qkv`, `attn_gate` on SSM blocks, `ssm_alpha`, `ssm_beta`, `ssm_conv1d`) are therefore checked for **presence** in the validator, with exact relational shapes required for everything the public record + filed header pin down (globals, norms, router, routed experts, shared expert, attention projections, `ssm_out`, `ssm_a`, `ssm_dt.bias`, `ssm_norm`). Tightening the presence-only shapes is named follow-on work for the slice that runs the real header census (J-133 / J-136, §0.6).
