## 3. Design — the proof construction

**`aesir_engine/tests/test_speculative_identity.mojo`** (new; 8 groups) drives the real J-072 loop — `run_loop` for the all-right configurations, `run_loop_round` round-by-round where the configuration needs per-round planning (capacity shortening, F) or per-round slot/proposer-KV handling (slot switching, G), and a spec driver over `run_loop_round` for the adversarial configurations (C, D, E). Every configuration shares the same assertions:

- the plain continuation is a stated deterministic stream (`(i*37 + seed*1013) mod 4000 + 17`, a distinct seed per configuration); each round's target list is that stream's next k+1 tokens — the account-level premise, stated in the test header with its honesty grade;
- **emission == plain, token-for-token**, checked by J-071's `sequences_identical` and `identity_first_divergence == -1` over the whole generation;
- **final state == plain state**: KV length and context count equal start + generation length; the RNG word equals its start word; proposer KV equals start + total accepted (own-KV proposers) or its start/sentinel value untouched (head and conversation proposers; G uses sentinel 777 for the non-cross rounds so a touch would be visible);
- per-round account totals (accepted, rollback rows) accumulated from the returned accounts and asserted against both the spec formula (spec driver) and the exact filed numbers in §5's table.

**Closing rounds, stated honestly (a property of the slicing model, §6):** in the flat slicing model a round's target list is the continuation's next k+1 tokens, so a generation cannot *end* on a low-acceptance round whose slice would run past the continuation — the last round must consume the remainder exactly. Configurations C, D, and E therefore end with stated all-right closing rounds at a stated k (part of each spec, never hidden); the stretches under test (295 zero rounds in C, the alternating pairs in D, the traps in E) are the rounds before them. In the spec driver, target lists are sliced from a source stream 16 tokens longer than the generation: entries past the generation's end are pass-position choices on draft contexts, discarded by their round and never emitted or compared; the identity assertion compares only the generation itself.
