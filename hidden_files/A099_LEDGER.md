- XCLBIN_LOAD_FAILED: REAL XRT exceptions, three ways, all under sudo with the device open (device_name=NPU Strix Halo in-log): missing file (No such file), garbage file (xclbin: buffer too small to contain header), injected bad path; plus the no-artifacts call (argc<8). Logs fb_xclbin_missing_sudo.log / fb_xclbin_garbage_sudo.log / fb_xclbin_fault.log / fb_noargs.log.
- INSTR_LOAD_FAILED: REAL - instrs path nonexistent (fb_instr_missing.log); bad-size branch shares the same fallback helper.
- KERNEL_RUN_FAILED + KERNEL_TIMEOUT: contract-layer injection (env-forced, decided BEFORE any run object is created - an earlier build injected after run start and XRT aborted on teardown of the live run object; that defect was found by these tests and fixed in-slice). Honest limit: a genuine mid-run XDNA failure or hang cannot be forced safely on the shared device; the branches that consume a non-COMPLETED ert state (verification, warm, e2e) route through the same fallback_to_cpu, and the happy path proves those states return COMPLETED in-log. Logs fb_run_fault.log / fb_timeout_fault.log.
- OUTPUT_MISMATCH: REAL NPU run (ert COMPLETED, device evidence in-log), one output element corrupted after sync: detector saw mismatches=1, discarded the NPU result, fallback exact (fb_mismatch_fault.log). This is the never-a-silent-wrong-answer proof.
- Happy path regression: 64x64x64 on the real NPU, NO fallback: 4096 elements, 0 mismatches, 0 sentinels, checksum 16383547698108786409 = banked A-092/A-095 checksum reproduced; 30 dispatches (npu_happy_64.log).

## Parity note (raw-oracle discipline)
- The offload executes through the host runner, not inside the Mojo engine (no in-engine XRT bridge; gemm_f16_npu stays fail-closed GPU-002), and the registry flag defaults OFF, so the shipping engine is bit-identical to base. Op-level exactness (integer GEMM, memcmp vs the int64 CPU oracle) is the correctness bound for this slice, and the fallback inherits it by construction: the fallback output IS the CPU path output, re-verified before acceptance. Model-level teacher-forcing parity is not claimed (not applicable until a bridge slice).
