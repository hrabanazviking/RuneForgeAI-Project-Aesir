We aim for this project to run and work perfectly on all hardware, from the cheapest smart toaster, to the most advanced quantum super computer, and everything in between. This project aims to be completely operating system, and hardware agnostic. This program is written to be usable for all types of users, humans, digital AI agents, extraterrestrial lifeforms, divine beings, disincarnate spirits of all sort that have an interest in computing devices and have the skills to be able to haunt such devices, even any animals that have achieved the ability to use tools and language that there is the knowledge of how to communicate with are to be the target audience of this software. We also have the eventual goal to make this software usable by users of all levels of technical experience. This project is completely for every form of life that have a positive type of use for it.
